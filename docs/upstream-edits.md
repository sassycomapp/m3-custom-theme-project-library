# Edits to base (upstream v1.2.6) files

Every change to a file that came from Anvil's theme is listed here, so upstream merges (Step 11) can be resolved. Format: file, change, reason, step.

| File | Change | Reason | Step |
|---|---|---|---|
| `anvil.yaml` | `name` set to `m3-custom-theme`. The startup module `_TestForms.ButtonMenuFUI`, which does not exist in the public repo, was replaced by `startup_form: Form1`. The editor also reformatted one line. | Make the app run. | 1 |
| `.gitignore` | Added `/.anvil/`. | Anvil's local folder. | 1 |
| `.anvil_editor.yaml` | Added ids for every m3x file: `Form1`, `m3x/palettes.css`, `_utils.m3x_theming`, `m3x/tokens.css`, `_utils.m3x_presets`, `m3x/components.css`, and each component's form, CSS file and toolbox icons. | New files. | 1, 4, 5, 6 |
| `theme/assets/theme.css` | (a) Added `@import '_/theme/m3x/palettes.css';` after the base imports. (b) Added the variable `--anvil-m3-on-background` to the `:root` block. (c) Replaced 55 direct `%color:...%` tokens after the `:root` block with the matching `var(--anvil-m3-...)`. Each replaced token has the identical value in light mode. | Palettes and dark mode must reach the whole theme, including the page background, navigation, modal and data grid. | 4 |
| `theme/assets/theme.css` | (d) Added `@import '_/theme/m3x/tokens.css';` after the palettes import. (e) Added 20 `--m3x-color-*` variables to the end of the `:root` block, one per M3 colour role the base lacks, each set from its `%color:...%` token. | The token layer, and the extra colour roles in Anvil's colour scheme. | 5 |
| `theme/assets/theme.css` | (f) Added `@import '_/theme/m3x/components.css';` after the tokens import. | Every m3x component's CSS is imported from `m3x/components.css`, so new components never touch `theme.css`. | 6 |
| `anvil.yaml` | Added each m3x component to `toolbox_sections` (Dialog: Display section). | Designer support. | 6 |
| `client_code/components/__init__.py` | Added one export line per m3x component (`Dialog`). | `import m3.components as m3` reaches the component. | 6 |
| `theme/parameters.yaml` | The `color_scheme` section is generated by `tools/build_palettes.py`: the base colour list keeps its 46 values and gains the 20 extra colour roles; the 8 base presets (Material, Rally, Mykonos, Manarola) are replaced by 10 presets, one per palette and mode. The `roles` section is unchanged. | Anvil's Theme editor offers exactly the theme's palettes, and every preset matches the light/dark switch. | 5 |
